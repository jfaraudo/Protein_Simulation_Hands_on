# Analysis of a Protein Simulation
Data files for the [Quickstart tutorial](https://userguide.mdanalysis.org/stable/examples/quickstart.html) example in MDAnalysis python library for the unfolding of [adenylate kinase](https://www.rcsb.org/structure/1AKE) protein (PDB code: 1AKE).

The example notebook follows closely (but not exactly) the official Quickstart tutorial.

The dataset corresponds to the paper by [Beckstein et al., 2009](https://www.sciencedirect.com/science/article/pii/S0022283609011164?via%3Dihub) as in the official tutorial.

Link with all files in a compressed zip file [here](https://saco.csic.es/s/Re2yikBwCJWDWX2)
